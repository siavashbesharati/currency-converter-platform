# Currency Converter Platform

This repository contains the currency-converter-platform project, which is a full-stack application with an ASP.NET Core 8 backend and a React + TypeScript frontend.

## Architecture Overview

The application is composed of two main parts: a backend API and a frontend web application.

### Backend

The backend is an ASP.NET Core 8 Web API that provides endpoints for currency conversion and exchange rate information. It is built with a focus on clean architecture, resilience, and security.

Key features:
- **Services and Providers:** The business logic is encapsulated in services, which use providers to fetch data from external sources. The `IExchangeRateProvider` interface allows for multiple providers to be implemented in the future.
- **Caching:** A two-layer caching strategy is implemented to improve performance and reduce calls to the external API. It uses an in-memory cache for short-term caching and a database-backed cache for longer-term storage.
- **Resilience:** Polly is used to implement retry and circuit-breaker policies for calls to the external Frankfurter API.
- **Authentication:** The API is secured using JWT authentication. A simple `TokenService` is provided for issuing tokens.
- **Rate Limiting:** The API is protected against abuse with rate limiting.
- **Logging and Correlation:** Serilog is used for structured logging, and a custom middleware adds a correlation ID to each request, which is then passed to the external API.

### Frontend

The frontend is a React application built with TypeScript and Vite. It provides a user interface for converting currencies, viewing the latest exchange rates, and browsing historical data.

Key features:
- **API Client:** A dedicated API client handles all communication with the backend. It uses `axios` interceptors to inject the JWT token and correlation ID into each request.
- **Component-Based:** The UI is built with a clean component structure.
- **Authentication:** The application has a simple login form and manages the user's authentication state.

## How to Run

### Using Docker Compose

The easiest way to run the application is with Docker Compose.

```
docker-compose up --build
```

The frontend will be available at `http://localhost:8080`.

### Running Locally

You can also run the backend and frontend separately.

#### Backend

```
# from repo root
dotnet run --project src/CurrencyConverter.Api
```

The API will be available at `http://localhost:5000`.

#### Frontend

```
cd client
npm install
npm run dev
```

The frontend will be available at `http://localhost:3000`.

## Future Improvements

- **More Providers:** The application is designed to be extensible with new exchange rate providers.
- **Frontend Tests:** The frontend currently has no tests. Component and/or integration tests could be added to improve the quality of the application.
- **Real-time Updates:** The frontend could be updated to provide real-time updates for the latest exchange rates.
- **User Management:** A more robust user management system could be implemented, with features such as user registration and password recovery.
- **Configuration:** The application could be made more configurable, for example, by allowing the cache expiration times to be set in the `appsettings.json` file.
