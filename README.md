# currency-converter-platform

This repository contains a scaffold for the currency-converter-platform project (ASP.NET Core 8 backend + React + TypeScript frontend).

See `.github/prompts/plan-currencyConverterPlan.prompt.md` for the implementation plan and AI usage notes.

Local run (backend):

```
# from repo root
dotnet run --project src/CurrencyConverter.Api
```

Frontend:

```
cd client
npm install
npm run dev
```
